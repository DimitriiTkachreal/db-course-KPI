# Laboratory Work №1

**Topic:** Database design and introduction to basic operations of the PostgreSQL DBMS.  
**Subject Area:** Online Electronics Store.  

## Description
The project implements a database architecture for managing an online store. The schema covers storing up-to-date information on available items with category hierarchy support, tracking registered users, and processing orders with a record of the purchased quantity.

## Directory Structure

* **/report** — Contains the final PDF report with a detailed business logic description and normalization analysis.
* **/diagrams** — Contains graphical files:
  * Conceptual ER-model in Crow's Foot notation.
  * Relational database schema.
* **/sql** — Contains the DDL script for deploying the table structure, keys, and constraints in PostgreSQL.
